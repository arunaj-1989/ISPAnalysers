# Skill 05: IPTV & Setup Box Services

## Issue Code Index
- `IPTV_COMPLAINT`
- `IPTV_NEW_REQUEST`
- `IPTV_STATIC_REQUEST`

---

### 1. IPTV_COMPLAINT
- **Keywords:** "STB freezing", "channel no signal", "IPTV error", "set-top box not working"
- **SOP:**
  1. Verify router fiber link is active (IPTV runs over same line).
  2. Guide customer to restart STB (Set-Top Box) and check HDMI cable connection.
  3. Check if issue is specific to particular channels or all channels.

### 2. IPTV_NEW_REQUEST
- **Keywords:** "add IPTV box", "STB connection", "new IPTV connection", "IPTV installation"
- **SOP:**
  1. Check broadband plan compatibility with IPTV addon.
  2. Quote STB hardware cost/monthly charge.
  3. Raise installation order for IPTV set-top box.

### 3. IPTV_STATIC_REQUEST
- **Keywords:** "static IP allocation for IPTV", "IPTV static IP", "fixed IP for IPTV"
- **SOP:**
  1. Confirm customer requirement for static routing for specialized IPTV setups.
  2. Assign Static IP block from pool in CRM and configure route on OLT/ONT.
