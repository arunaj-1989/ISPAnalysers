# Skill 04: Shifting, Cabling & Hardware Upgrades

## Issue Code Index
- `CABLE_CHANGE_REQUEST`
- `DEVICE_UPGRADE_REQUEST`
- `INTERNAL_SHIFTING_REQUEST`
- `RELOCATION_REQUEST`

---

### 1. CABLE_CHANGE_REQUEST
- **Keywords:** "பழைய கேபிள் மாத்தணும்", "வயர் டேமேஜ் ஆயிருக்கு மாத்துங்க", "wire damaged replace", "new cable line"
- **SOP:**
  1. Identify reason for cable replacement (wear and tear, rodent damage, line noise).
  2. Inform cabling charges if applicable beyond free limit.
  3. Schedule wiring technician.

### 2. DEVICE_UPGRADE_REQUEST
- **Keywords:** "புது ரவுட்டர் வேணும்", "டூயல் பேண்ட் ரவுட்டர் மாத்தணும்", "5G router upgrade", "Gigabit ONT switch"
- **SOP:**
  1. Check eligibility for device upgrade.
  2. Quote hardware upgrade fee or security deposit adjustments.
  3. Raise hardware dispatch ticket.

### 3. INTERNAL_SHIFTING_REQUEST
- **Keywords:** "ரூம் மாத்தி வைக்கணும்", "வீட்டுக்குள்ளயே ரவுட்டர் ஷிப்ட்", "move router inside room", "internal wire shift"
- **SOP:**
  1. Confirm exact location move inside house.
  2. Inform internal cabling labor charges.
  3. Schedule field installation technician visit.

### 4. RELOCATION_REQUEST
- **Keywords:** "வீடு மாறப்போறோம்", "கனெக்ஷன் வேற இடத்துக்கு மாத்தணும்", "shift connection new home", "relocate broadband"
- **SOP:**
  1. Collect target new address and pincode to verify Interjet network feasibility.
  2. If feasible, schedule uninstallation at current address and re-installation at new site.
