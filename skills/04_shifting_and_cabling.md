# Skill 04: Shifting, Cabling & Hardware Upgrades

## Issue Code Index
- `CABLE_CHANGE_REQUEST`
- `CONFIGURE_ROUTER`
- `DEVICE_UPGRADE_REQUEST`
- `INTERNAL_SHIFTING_REQUEST`
- `RELOCATION_REQUEST`

---

### 1. CABLE_CHANGE_REQUEST
- **Keywords:** "wire damaged replace", "new cable line", "replace cable", "change old cable"
- **SOP:**
  1. Identify reason for cable replacement (wear and tear, rodent damage, line noise).
  2. Inform cabling charges if applicable beyond free limit.
  3. Schedule wiring technician.

### 2. DEVICE_UPGRADE_REQUEST
- **Keywords:** "new router", "dual-band router upgrade", "5G router upgrade", "Gigabit ONT switch"
- **SOP:**
  1. Check eligibility for device upgrade.
  2. Quote hardware upgrade fee or security deposit adjustments.
  3. Raise hardware dispatch ticket.

### 3. CONFIGURE_ROUTER
- **Keywords:** "configure new router", "router configuration", "new router setup", "set up replacement router", "Wi-Fi setup", "configure Wi-Fi"
- **SOP:**
  1. Confirm that the router was newly installed or replaced and record its make/model.
  2. Verify WAN/ONT cabling and power status, then configure the required Internet connection settings.
  3. Configure the Wi-Fi name and password, test Internet access, and arrange a technician visit if remote configuration is not possible.

### 4. INTERNAL_SHIFTING_REQUEST
- **Keywords:** "move router inside room", "internal wire shift", "move router to another room", "relocate router inside home"
- **SOP:**
  1. Confirm exact location move inside house.
  2. Inform internal cabling labor charges.
  3. Schedule field installation technician visit.

### 5. RELOCATION_REQUEST
- **Keywords:** "shift connection new home", "relocate broadband", "move connection", "relocate internet service"
- **SOP:**
  1. Collect target new address and pincode to verify Interjet network feasibility.
  2. If feasible, schedule uninstallation at current address and re-installation at new site.
